# Nekopara Vol.2 - Türkçe Yama (v0.2.1)

DeepL ile hazırlanmış, resmi olmayan çeviri yamasıdır.

**Durum:** Metinler %- | Görseller %- 
> **Not:** Çeviride hatalar bulunuyor ve bazı fonksiyonlar oyunda çökmeye yol açmaktadır.

## Kurulum
1. Yukarıdaki butondan `Nekoo!.zip` dosyasını indirin.
2. İçindeki `patch2.xp3` dosyasını oyun klasörüne atın. *(Örn: `...\steamapps\common\NEKOPARA Vol. 2`)*
3. Oyundan **Config** menüsüne girip **UI:** `English`, **Main Text:** `日本語` yapın.
